**YouTube Music overlay showing currently playing music**

A program that opens a small window displaying the currently playing music from YouTube Music, allowing you to easily see the title and artist, pause playback, or switch to the previous or next track.

-----

# Installation
To install the application, either build the EXE file yourself or download the latest version from Releases, then run the .exe file.
Additionally, to have the data read from YouTube Music, you need to add an extension that will send the data to the application.

-----

# Overview

The window will display the music that is currently playing. It is fully interactive, allowing you to click on various buttons directly. Additionally, the window will always stay on top of other applications and can be moved to any position on the screen.

![1](https://github.com/user-attachments/assets/5b4a8ac8-5f22-4832-ade2-0a80677b3f53)

# Settings

In the application settings, you can customize several features, such as:
 - Border animations – bars around the window that are synchronized with the music.
 - Glow border – a glowing effect on the border that adds a nice visual touch.
 - Background image animation – the background image moves with the beat of the music.

![2](https://github.com/user-attachments/assets/ff3e7f18-95f3-4895-81cd-84b9da4d6877)

# Video Background Sync

The window background will play the video of the currently playing track. If the song doesn’t have a music video, the overlay will simply display a static image.
> [!NOTE]
> If you want the background to remain static at all times, you can enable the Static Background Image option in the settings.
